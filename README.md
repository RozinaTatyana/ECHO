# ECHO° — DIGITAL MEMORY ARCHIVE

Готовый статический сайт. Откройте index.html в браузере — установка не требуется.

## GitHub Pages
1. Загрузите содержимое папки echo в корень репозитория.
2. Settings → Pages → Deploy from a branch → main → / (root) → Save.
3. Откройте адрес, показанный GitHub Pages.

Все пути относительные. Фото локальные, системные шрифты. API, сборка и серверная часть не нужны. Escape закрывает фото; Tab и Enter позволяют управлять с клавиатуры. На сенсорных устройствах остается стандартный курсор. Reduced motion отключает движение.

Тексты воспоминаний и даты — художественные. Источники фото в CREDITS.md. Заменить фото можно файлами с теми же именами в images/.
